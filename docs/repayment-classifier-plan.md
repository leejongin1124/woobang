# 변제금 상환내역 분류·수수료 계산 엑셀 프로그램 계획서 (초안)

> 상태: 1차 구현 완료 (`repayment-classifier/`). 회사 엑셀에서 실제 파일로 확인 남음.
> 이 문서에는 실제 고객 정보를 넣지 않는다. 예시 숫자는 2026-10-30 합계값만 쓴다.

## 1. 한 줄 요약
신용회복위원회에서 받은 `변제금상환내역조회` 엑셀 1개를 넣고 버튼 한 번 누르면
① **새출발기금 파일**, ② **일반(나머지) 파일** 두 개가 원본 서식 그대로 만들어지고,
③ **수수료 계산 시트**에 구분별 수수료(3.88%, 원 미만 절사)와 법인계좌 입금 예정액이 표시된다.
작업이 끝나면 [초기화] 버튼으로 비우고 다음 날 다시 쓴다.

## 2. 보안 원칙 (외부 유출 금지)
- 인터넷·AI·외부 서버를 전혀 쓰지 않는 **엑셀 매크로(VBA) 파일(.xlsm) 1개**로 만든다.
- 프로그램 파일 안에는 고객 데이터를 **저장하지 않는다**. 원본 파일을 읽어 결과 파일만 같은 PC 폴더에 만든다.
- [초기화]는 계산 시트의 숫자와 임시 데이터를 모두 지운다.
- 개발·테스트는 **가짜 데이터**로만 한다. 실제 파일은 사용자 PC에서만 연다.

## 3. 원본 파일에서 읽는 열 (사진 기준)
No, 회차, 일시납감면율, 처리일자, 지점명, 고객명, 고객식별번호, **지원구분**, 채무구분,
주채무자주민등록번호, 주채무자, 계좌번호, 원금, 이자, 기타채무, **합계**, 확정채권금액, 변제금수취계좌, 지로코드
- 맨 위 제목줄: `변제금상환내역조회(총 N건)`, 거래코드, 출력일시, 사용자명

## 4. 분류 규칙
| 구분 | 판정 기준 | 결과 파일 |
|---|---|---|
| 새출발 | `지원구분`에 "새출발기금" 포함 | `새출발_YYYYMMDD.xlsx` |
| 중도완제 | 자동 분류 안 함. 계산표에 **수기 입력** (결정 2026-10-30) | 없음 |
| 일반 | 위에 해당하지 않는 나머지 | `일반_YYYYMMDD.xlsx` |

- 결과 파일은 sERP [엑셀 업로드]에 바로 올릴 수 있게 **원본과 같은 열·순서·제목줄**을 유지하고 행만 나눈다.
- 제목줄의 `총 N건`은 나뉜 건수로 고친다.

## 5. 수수료 계산 시트 (첨부한 "변제금 상환내역 수수료 계산기" 양식 그대로)
| 구분 | 수수료율 | 수수료 | 차감입금액 | 원금(합계) | sERP금액 | 차이금액 |
|---|---|---|---|---|---|---|
| 중도완제 | 3.88% | 자동 | 자동 | 자동 | 직접 입력 | 자동 |
| 새출발 | 3.88% | 자동 | 자동 | 자동 | 직접 입력 | 자동 |
| 일반 | 3.88% | 자동 | 자동 | 자동 | 직접 입력 | 자동 |
| 총계 | | 합계 | 합계 | 합계 | 합계 | 합계 |

- 원금(합계) = 해당 구분 `합계` 열의 합
- 수수료 = ROUNDDOWN(원금(합계) × 3.88%, 0) — 구분별로 따로 계산
  - 검증: 597,178 × 3.88% = 23,170.5 → **23,170** / 103,921 × 3.88% = 4,032.1 → **4,032** (신복위 확인서와 일치, 즉 절사)
- 차감입금액 = 원금(합계) − 수수료 → **법인계좌에 들어와야 할 금액** (574,008 / 99,889, 통장 입금과 일치)
- 법인계좌 실제 입금액 입력칸을 두고, 차감입금액과 다르면 빨간색 표시
- 차이금액 = 원금(합계) − sERP금액, 0이 아니면 빨간색 표시
- 수수료율은 칸 하나에서 바꿀 수 있게 한다 (내년 요율 변경 대비)

## 6. 매일 작업 순서
1. 신복위에서 `변제금상환내역조회` 엑셀 다운로드
2. 프로그램 열기 → [파일 불러오기] → 다운받은 파일 선택
3. 자동으로: 분류 → 결과 파일 2개 생성(같은 폴더) → 계산 시트 채움
4. 통장(계좌현금수납확인)에서 신복위 입금액 2건 확인 → 입금액 칸에 입력 → 일치 확인
5. sERP 신용회복수납처리에서 파일별로 [엑셀 업로드] → 총 입금금액(원금 합계) 입력 → 자동점검 → 수납처리 (2번 반복)
6. sERP 처리금액을 sERP금액 칸에 입력 → 차이 0 확인
7. 필요하면 계산 시트 인쇄 → [초기화]

## 7. 만들 것
- `변제금분류기.xlsm` 하나 (시트: 사용법 / 수수료계산 / 설정)
- 버튼: [파일 불러오기] [초기화] [계산표 인쇄]
- 예외 처리: 열 이름이 바뀌었거나 지원구분 값이 처음 보는 값이면 멈추고 알림

## 8. 결정 사항 (2026-10-30)
1. 중도완제: 계산표에 칸만 두고 수기 입력
2. 회사 PC 매크로 허용 → .xlsm
3. 다운로드 파일 형식: .xlsx
4. 처음 보는 지원구분 값이 있어도 멈추지 않고, 불러온 뒤 지원구분별 건수를 보여 준다 (새출발 포함 여부만으로 분류)

## 9. 남은 확인 (회사 PC에서)
- 실제 다운로드 파일로 분류가 맞는지, sERP [엑셀 업로드]가 나뉜 파일을 그대로 받는지
- 엑셀 버전에 따라 단추·빨간색 표시가 정상인지
